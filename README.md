# TournamentAssistant
A program designed to make it easier to coordinate tournaments for the VR rhythm game Beat Saber

## Replay format
TournamentAssistant records replays in TARF, the TournamentAssistant Replay Format. See [TARF/README.md](TARF/README.md) for the specification and a converter from BeatLeader and ScoreSaber replays.
